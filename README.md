# 🎮 坦克大战 - Tank Battle

一个使用纯 HTML + CSS + JavaScript 制作的经典坦克大战游戏，无需任何外部依赖，直接在浏览器中打开即可游玩！

## 🚀 在线试玩

在浏览器中打开 `index.html` 文件即可开始游戏。

## 🎯 游戏特性

- ✅ **经典玩法**：还原经典坦克大战的核心体验
- ✅ **玩家坦克**：WASD 或方向键控制移动，空格/J键射击
- ✅ **敌方AI**：智能敌人自动追踪、射击
- ✅ **多关卡设计**：3个精心设计的关卡，难度递增
- ✅ **障碍物系统**：砖墙（可摧毁）、钢板（不可摧毁）、基地保护
- ✅ **视觉效果**：爆炸特效、坦克动画、发光子弹
- ✅ **得分系统**：消灭敌人获得分数
- ✅ **生命值系统**：多条生命，被击中后可复活

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` / `J` | 发射子弹 |
